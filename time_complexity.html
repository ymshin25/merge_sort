O(n²) 이란?
버블 정렬 · 선택 정렬
데이터가 n개일 때
비교 횟수 ≈ n × n = n²번
왜 n²인가요?
바깥 반복문이 n번 돌고
안쪽 반복문도 n번 돕니다.
n × n = n²
n이 2배가 되면
연산은 4배 늘어납니다.
n이 10배가 되면
연산은 100배 늘어납니다!

for i in range(n):
  for j in range(n):
    # 이중 반복문 = O(n²)
O(n log n) 이란?
병합 정렬
데이터가 n개일 때
비교 횟수 ≈ n × log₂n번
log₂n 이 뭔가요?
n을 2로 몇 번 나눠야 1이 되나요?
8 → 4 → 2 → 1  = 3번 (log₂8 = 3)
1024 → … → 1 = 10번
n이 2배가 되면
연산은 2배 + 조금만 늘어납니다.
n이 10배가 되면
연산은 약 13배만 늘어납니다.
병합 정렬 구조
분할: log₂n 단계
각 단계 병합: n번 비교
# n × log₂n = O(n log n)
실제 숫자로 비교 — n별 연산 횟수
데이터 수 n O(n²) 버블·선택 O(n log n) 병합 몇 배 차이?
log₂n 직관적 이해 — "절반씩 나누기"
병합 정렬은 배열을 계속 절반으로 쪼갭니다.
몇 단계만에 원소 1개가 될까요? 그게 바로 log₂n입니다.
